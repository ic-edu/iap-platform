# 16. Contract-First API Design with OpenAPI 3.1

Date: 2026-07-26

## Status
Accepted

## Context
Clear API contracts are essential for mobile app developers and integration partners.

## Decision
Adopt Contract-First API design documented in `docs/api/openapi.yaml` (OpenAPI 3.1) and Postman Collection `docs/api/postman_collection.json`.

## Consequences
- Single source of truth for frontend and mobile SDK developers.
