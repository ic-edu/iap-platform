# Incident Response Guide — iC.edu Assessment Platform (IAP)

## Severity Levels
- **P1 (Critical)**: Platform offline, candidate CBT engine down.
- **P2 (High)**: Payment or certificate issuance failed.
- **P3 (Medium)**: Non-critical feature error.

## Emergency Contacts & Escalation
- DevOps Lead: `ops@icedu.org`
- Tech Lead: `lead@icedu.org`
