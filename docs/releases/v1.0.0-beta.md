# Release v1.0.0-beta — Production Readiness & Beta Release

Release Date: 2026-07-26

## Overview
`v1.0.0-beta` marks the completion of the initial 10-sprint development roadmap for the iC.edu Assessment Platform (IAP). The platform is now fully feature-complete, security-hardened, and ready for User Acceptance Testing (UAT).

## Key Milestone Features
- **Security Hardening**: Content Security Policy (CSP), X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, XSS sanitization, and Sanctum Bearer token security.
- **Observability**: Health probes (`/health`, `/ready`, `/live`) and Admin Monitoring Dashboard (`/admin/monitoring`).
- **Containerized Infrastructure**: Production `Dockerfile`, `docker-compose.yml`, Nginx, Supervisor, zero-downtime `deploy.sh`, and automated `backup-db.sh`.
- **Operations & User Documentation**: Complete suites in `docs/operations/` and `docs/user/`.
- **User Acceptance Testing (UAT) Package**: Test scenarios, bug report template, and sign-off forms in `docs/uat/`.
- **Automated Verification**: **150+ Pest Tests Passed** with 0 migration errors, 0 Pint formatting issues, and 0 Larastan / PHPStan level 5 errors.
