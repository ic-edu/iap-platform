# Release v0.8.0 — Sprint 8: Commerce & Billing Platform

Release Date: 2026-07-26

## Highlights
- **Lightweight DDD Commerce Architecture**: Introduced `app/Modules/Commerce/` with Domain, Application, Infrastructure, and Presentation layers.
- **Product Catalog & Pricing Engine**: Full support for TOEFL, IELTS, Placement Test, Prep Course, and Membership products with single-source `PricingEngine`.
- **Cart, Checkout & Invoice Engines**: Automated shopping cart calculations, ULID invoice generation (`INV-YYYYMMDD-XXXX`), and 24-hour expiration rules.
- **Payment Gateway Abstraction**: Interface contract (`PaymentGatewayInterface`) with `ManualTransferGateway` (Production Ready) and drivers for Midtrans, Xendit, and Stripe.
- **Automatic Enrollment Activation**: Event-driven activation (`PaymentConfirmed` → `ActivateEnrollmentOnPayment` → `EnrollmentEngine` & `AssignmentEngine`).
- **Product Documentation Suite**: Dedicated `docs/product/` directory containing vision, user personas, business rules, feature matrix, acceptance criteria, and release plan.
- **Automated Verification**: **110+ Pest Tests Passed** with 0 migration errors, 0 Pint issues, and 0 PHPStan errors.
