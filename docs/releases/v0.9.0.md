# Release v0.9.0 — Sprint 9: API Platform & Integration Layer

Release Date: 2026-07-26

## Highlights
- **REST API v1 Platform**: Introduced `/api/v1` routes with standard JSON responses (`success`, `message`, `data`, `meta`).
- **Sanctum API Authentication**: Token login, logout, me endpoints, token revocation, multi-device support.
- **14 API Resources**: Full coverage for Academic, Assessment, QuestionBank, Certificate, Commerce, and Reporting domain models.
- **Webhook Engine**: `WebhookEngine.php` with HMAC-SHA256 signature computation (`X-IAP-Signature`), delivery logging, and retries.
- **Integration Layer Contracts**: Interfaces & drivers for Zoom, Google Calendar, WhatsApp, SMS, Email, Payment, and Storage.
- **API Audit Logging & Rate Limiting**: Middleware `ApiAuditLogMiddleware.php` recording request latency and metadata.
- **OpenAPI 3.1 & Postman Collection**: Contracts in `docs/api/openapi.yaml` and `docs/api/postman_collection.json`.
- **SDK Preparation Structure**: Directories and documentation for `sdk/php/`, `sdk/javascript/`, and `sdk/flutter/`.
- **Architecture Review Quality Gate**: Inserted Architecture & Beta Readiness Review checklist before Sprint 10.
- **Automated Verification**: **130+ Pest Tests Passed** with 0 migration errors, 0 Pint issues, and 0 PHPStan errors.
