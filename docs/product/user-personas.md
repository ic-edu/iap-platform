# User Personas — iC.edu Assessment Platform (IAP)

## 1. Candidate / Student
- **Goal**: Browse courses & tests, purchase products via cart/checkout, complete CBT evaluations without technical friction, and download verified digital certificates.
- **Pain Points**: Complicated checkout flows, unreliable exam timers, page refresh losing progress.
- **Key Features Used**: Candidate Portal, Distraction-Free CBT Interface, Cart & Checkout, Certificate Download.

## 2. Administrator
- **Goal**: Manage system settings, monitor platform health, oversee question banks, publish tests, manage orders, and issue/revoke certificates.
- **Pain Points**: Lack of visibility into server health, manual billing verification, lack of audit trails.
- **Key Features Used**: Admin Platform Dashboard, Commerce Portal, Queue & Health Monitoring, Audit Activity Logs.

## 3. Teacher / Evaluator
- **Goal**: Author passages and multi-format questions (12 types), build tests with section rules, assign evaluations to student batches.
- **Pain Points**: Tedious manual scoring, difficulties organizing question banks.
- **Key Features Used**: Rich Question Editor, Test Builder, Assignment Engine, Item Analysis.

## 4. Finance & Operations Manager
- **Goal**: Monitor revenue, track invoice statuses (unpaid, paid, expired), manage pricing rules and coupons, oversee subscription renewals.
- **Pain Points**: Unclear revenue reporting, manual payment reconciliation.
- **Key Features Used**: Finance Dashboard, Pricing Engine, Coupon Management, Billing & Export Services.
