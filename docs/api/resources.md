# API Resources Documentation — iC.edu Assessment Platform (IAP)

All API responses follow the uniform JSON envelope format:

```json
{
  "success": true,
  "message": "Resource operation completed successfully.",
  "data": {},
  "meta": {}
}
```

## Available Resources
- `UserResource`, `CourseResource`, `EnrollmentResource`, `QuestionBankResource`, `QuestionResource`, `TestResource`, `AttemptResource`, `ResultResource`, `CertificateResource`, `ProductResource`, `OrderResource`, `InvoiceResource`, `PaymentResource`, `SubscriptionResource`.
