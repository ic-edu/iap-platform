# Integration Layer Abstraction Documentation — iC.edu Assessment Platform (IAP)

IAP uses driver-based interface contracts for third-party service integration:
- `ZoomIntegrationInterface`: Virtual class & proctoring.
- `GoogleCalendarIntegrationInterface`: Assessment scheduling.
- `WhatsAppIntegrationInterface`: Instant mobile alerts.
- `SMSIntegrationInterface`: SMS OTP & notifications.
- `EmailIntegrationInterface`: Transactional email.
- `PaymentIntegrationInterface`: Payment processing.
- `StorageIntegrationInterface`: Media & PDF storage.
